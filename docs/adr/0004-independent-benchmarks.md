# Independent benchmarks remain separate from catalogue and popularity

Accepted 2026-10-08, following the user's request for capability-first model ordering, filters and comparison charts.

Model Lab opens with selected variants ranked by the sourced Artificial Analysis Intelligence Index. The initial ten-variant snapshot records public numerical facts checked on 8 October 2026, with per-model attribution and reasoning settings. It is neither exhaustive nor a live market ranking. Popularity, provider-reported speed and API-route pricing remain separate datasets.

Null measurements remain unknown, sort last in both directions and are omitted from charts. Release-date plots show current scores by release date, not historical performance. End-to-end response time is used only when reported, never inferred from throughput. Context sizes may reflect rounded source figures.

An optional ARTIFICIAL_ANALYSIS_API_KEY Actions secret enables server-side daily retrieval through the documented free API with pagination. No key reaches the browser. Validate the complete response before replacing data; absent credentials or failed refreshes retain the last valid snapshot and its date. Metadata excluded from the free API is retained for exact matching slugs from the checked snapshot, otherwise unknown. Visible methodology explains this provenance.

The shipped bootstrap remains explicitly dated until credentials are configured. This amends the external-only benchmark decision in ADR 0002 and the benchmark exclusion in ADR 0003 without changing their source-attribution or pricing safeguards.
