# Static publication with client-side discovery

Use React/TypeScript and Vite for interactive browsing. Generate static paths and metadata for published stories, plus RSS and sitemap at build time. Keep the editorial collection in version control; require source checking before publication. This avoids a database, mandatory account and paid API dependency. GitHub Discussions provides the community space. Bookmarks and theme are browser-local. A static snapshot needs a content change and deployment to update; do not call it a live feed.
