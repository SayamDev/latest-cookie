# Domain context

A story is an original short summary linked to a primary source. Publication date belongs to that source; collection date records when Latest Cookie checked it. A briefing is a curated group of published stories. A bookmark belongs to the current browser. Community conversations live on GitHub Discussions, outside this static application.

Model Lab is a separate manually maintained catalogue in src/data/models.json. An entry records provider, standard uncached text input/output USD rates per million tokens, token-limit semantics, maximum output, accepted modalities, primary source links, and a checked date. Token volume in the calculator is aggregate, not one request. It does not measure intelligence, latency or throughput. The comparison URL contains only selected public model IDs, filters and entered token volumes; no API is called.
