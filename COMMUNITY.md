# Community guidelines

Be curious, specific and kind. Critique ideas and code, not people. Share sources and disclose affiliations. Beginners are welcome. No harassment, discrimination, spam, doxxing or malicious links.

Use GitHub Discussions for questions, projects and interesting finds. Posting requires a GitHub account. Report abusive content with GitHub's report controls; avoid repeating personal information in public reports. Maintainers may remove harmful contributions and restrict repeat offenders.
